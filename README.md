# AI Investor Radar

AI-powered investment intelligence platform.

## Current Stage

Phase 1 — Architecture, database, authentication and permissions.

## Technology

- React
- TypeScript
- Supabase
- PostgreSQL
- Supabase Auth

## Core Principle

The system does not depend on mandatory paid third-party infrastructure.

Public investment intelligence is shared across users.

User-specific data is separated from public investment intelligence.

## Development Strategy

GitHub
→ Supabase

→ Lovable frontend
